# 登錄預約週曆：選個別教練只顯示該教練 — 設計規格

- 日期：2026-07-06
- 狀態：業主已核可

## 目標

登錄預約頁籤的教練下拉（管理者才有）：

- 選**個別教練** → 週曆**只顯示該教練**的一對一預約與團課場次（現況是顯示全部、把其他教練淡化）。
- 選**「全部教練」** → 才顯示所有教練的行事曆（現況不變，含教練名標籤）。
- 非管理者教練本來就只看自己，不受影響。

## 做法（純前端 `public/coach.js` ＋ 清理 `public/style.css` 死樣式）

- **資料來源改用既有單教練路徑**：`renderRegister()` 的週資料 URL——
  - 選個別教練：`GET /api/coach/week?start=…&coachId=X`（**不帶 all=1**；走既有 `resolveCoach`，管理者可代任一教練，只回該教練的 bookings／groupSessions／availableSlots）。
  - 全部教練：`GET /api/coach/week?all=1&start=…`（不變）。
  - 後端零改動（server.js:865-879 與 resolveCoach:724 已支援）。
- **移除死程式碼**：淡化渲染只在「個別教練＋他人資料」時觸發，改抓單教練資料後永遠不會發生——
  - coach.js 週格渲染的 `other` 判斷與 `reg-booked-other` class 及他人教練名後綴（約 626-627 行）移除；教練名標籤只在「全部教練」（`isAll`）顯示，維持現狀。
  - style.css `.reg-booked-other` 兩條規則（1168-1169）刪除。
- 其餘不動：`regTargetBody` 的 coachId 帶入、拖曳改期、底色（availableSlots 兩種模式都有）、登錄彈窗流程、預設選自己（PR #86）。

## 行為差異備註

- 個別教練檢視下，其他教練已佔的時段現在會顯示成可點的「＋」空格——**這是正確的**：不同教練同時段本就可各自開課（撞課檢查是 per 教練），管理者可直接在該格替所選教練登錄。
- 資料量也較小（不再抓全店整週）。

## 驗證

`node --check` ＋ Playwright：管理者登入 → 登錄預約 → 選王教練：格子只出現王教練的課（無淡化他人課、無教練名後綴）；切「全部教練」：多教練課全部出現且帶教練名；再選回個別教練後點空格登錄流程照常；0 console error。既有 `test:api` 迴歸（後端未動）。
