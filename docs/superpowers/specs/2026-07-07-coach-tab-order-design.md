# 教練後台頁籤順序＋預設登錄預約 — 設計規格

- 日期：2026-07-07
- 狀態：業主指示（附截圖紅框）

## 目標

教練後台頁籤順序改為：**登錄預約、我的預約、可預約時段、個人資料**；進入教練後台**預設顯示登錄預約**（教練日常主要操作）。

## 做法（純前端）

- `coach.html`：頁籤按鈕重排，`tab-active` 移到登錄預約；panel 初始 `hidden` 對調（`tab-register` 顯示、`tab-bookings` 隱藏）。
- `coach.js`：開機由 `await renderBookings()` 改為 `switchTab('register')`（單一入口，順帶處理管理者共用教練下拉在登錄頁籤的隱藏邏輯）；我的預約改為切到該頁籤時才渲染（switchTab 既有行為）。
- 管理者預設選自己（PR #86）與單教練檢視（PR #88）行為不變。

## 驗證

Playwright：登入教練後台 → 預設 active 頁籤為登錄預約、週曆直接渲染、（管理者）共用下拉隱藏；切「我的預約」列表照常；頁籤順序正確；0 pageerror。
